How to Configure Worker Secrets

CLI Execution

Execute the following commands in your local workspace terminal where Wrangler CLI is configured to write keys to the worker environment:

Terminal 
# Set Microsoft Entra Tenant ID
echo "your-tenant-uuid" | npx wrangler secret put ENTRA_TENANT_ID

# Set Microsoft Entra App registration Client ID
echo "your-client-app-uuid" | npx wrangler secret put ENTRA_CLIENT_ID

# Set Microsoft Entra App registration Client Secret
echo "your-secret-string" | npx wrangler secret put ENTRA_CLIENT_SECRET
Terminal 
# Set OneLogin REST API Client ID
echo "your-client-id" | npx wrangler secret put ONELOGIN_CLIENT_ID

# Set OneLogin REST API Client Secret
echo "your-client-secret" | npx wrangler secret put ONELOGIN_CLIENT_SECRET

# Set OneLogin Domain Prefix (e.g. contoso-admin)
echo "your-subdomain" | npx wrangler secret put ONELOGIN_SUBDOMAIN

# Set API Domain Region (us or eu)
echo "us" | npx wrangler secret put ONELOGIN_REGION
